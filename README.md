# Лендинг AirPods Max (Next.js 14, App Router, TypeScript)

## Запуск
```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

## Структура
- app/ - layout.tsx, page.tsx, globals.css
- components/ - Header, Hero, Features, Footer, NeoButton (+ *.module.css)
- public/images/ - изображения, вырезанные из референса
- docs/reference.jpg - референс
